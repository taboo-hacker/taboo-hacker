## 从日常问题开始

这些项目的入口不同，出发点相同：把反复遇到的麻烦，变成一次顺手的操作。

### [QZCT Login](https://github.com/taboo-hacker/qzct-login) · 让校园网登录更直接

为衢州职业技术学院做的桌面登录助手，把 WiFi 连接和校园网认证放进一个界面。最近的一轮改进将「一键登录」与定时规则分开，让每天最常用的操作更直接。

<sub>Python / PySide6 · <a href="https://github.com/taboo-hacker/qzct-login/releases">下载发布版</a></sub>

### [Dark Mode & Reader](https://github.com/taboo-hacker/simple-dark-mode-reader) · 让网页适合阅读

给 Chrome 和 Edge 做的网页增强扩展，把深色主题、阅读净化、视频控制与常用工具放在一起。浏览器是每天待得最久的地方之一，我想让它用起来更舒服。

<sub>JavaScript / Chromium Extension · <a href="https://github.com/taboo-hacker/simple-dark-mode-reader#readme">功能与安装</a></sub>

### [Novel Reader](https://github.com/taboo-hacker/novel-reader) · 让本地文本打开就能读

用 Python 标准库搭建的本地 Web 阅读器，支持 ZIP 文本解析、章节识别与响应式阅读界面。这是一次轻量实现的尝试：尽量减少依赖，把精力留给阅读本身。

<sub>Python / Local Web · <a href="https://github.com/taboo-hacker/novel-reader#readme">使用说明</a></sub>

### [Endfield Calculator](https://github.com/taboo-hacker/endfield-material-calculator) · 让物资规划更清楚

把终末地的多地区收益、调度策略和图表展示做成计算工具。页面资源放在本地，离线也能使用，方便在不同方案之间做比较。

<sub>JavaScript / Chart.js · <a href="https://github.com/taboo-hacker/endfield-material-calculator#readme">项目说明</a></sub>

## 把一个想法做完整

做这些工具时，我会沿着使用过程把各部分连接起来：用 **Python、JavaScript / TypeScript** 写逻辑，用 **PySide6、Vue 或 React** 做界面，再根据需要补上 API、数据存储与部署。

我也在把 AI 融入开发流程，用它辅助梳理思路、编写代码、审查和重构；自己负责取舍、验证，以及判断实际用起来是否顺手。项目里的测试、GitHub Actions 和日常反馈，帮助我把一次实现变成持续迭代。

除了 GitHub 上的工具，我还在维护[个人主站](https://www.leo43991314520.top)和[自建 Git 服务](https://git.leo43991314520.top)，继续练习从界面、服务到 Linux 部署的完整过程。
